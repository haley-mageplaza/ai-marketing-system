# Shopplaza B2B Funnel

## Funnel Overview

Shopplaza B2B operates TWO funnels:

### A. Website Funnel
SEO → Blog → Landing → Conversion

### B. App Funnel
Discovery → Evaluation → Install → Retention

---

## Website Funnel

### TOFU (Awareness)
Goal: Drive traffic

Content: Guides, definitions (e.g., "What is Shopify B2B?")

CTA: Soft — learn more, explore

### MOFU (Consideration)
Goal: Evaluate solutions

Content: Best apps, comparisons (e.g., "Best Shopify apps for B2B")

CTA: Introduce apps — see features, compare

### BOFU (Decision)
Goal: Convert

Content: Landing pages, app-focused content

CTA: Install app

---

## App Funnel

### Discovery
- App Store search
- Blog referrals
- Social media

### Evaluation
- Reviews and ratings
- Feature comparison
- Use cases

### Conversion
Install app

### Retention
- UX quality
- Support responsiveness
- Regular updates

---

## Funnel Rules

- TOFU → MOFU
- MOFU → BOFU
- BOFU → Install

---

## B2B Funnel Characteristics

- Longer consideration cycle than B2C
- Education-heavy TOFU and MOFU content
- Emphasis on operational outcomes over quick wins
- Decision often involves evaluating multiple apps together (e.g., Hide Price + Request a Quote)
- Cross-app adoption is a key retention strategy
