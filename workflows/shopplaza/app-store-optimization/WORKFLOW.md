# Workflow: Shopplaza App Store Optimization

## Purpose

Comprehensive ASO workflow for optimizing one or more Shopplaza app listings on the Shopify App Store.

## Required Context

- `brands/shopplaza/brand/` — brand identity
- `brands/shopplaza/shared/aso-rules.md` — Shopplaza ASO methodology
- `brands/shopplaza/shared/seo-rules.md` — SEO-to-ASO bridge rules
- `brands/shopplaza/b2b/` or `brands/shopplaza/b2c/` — relevant product line
- `brands/shopplaza/b2b/apps/<app>.md` or `brands/shopplaza/b2c/apps/<app>.md` — specific app(s)

## Relevant Skills

1. `/market aso <app-listing-url>` — listing audit and optimization
2. `/market competitors <app-listing-url>` — marketplace competitor analysis
3. `/market copy <app-listing-url>` — listing copy optimization
4. `/market landing <app-listing-url>` — listing conversion analysis

## Execution Sequence

1. **Listing Audit** — Run ASO audit on the target app listing
2. **Competitor Scan** — Identify and analyze top competitors in the same category
3. **Copy Optimization** — Generate optimized listing copy (title, subtitle, description)
4. **Conversion Analysis** — Evaluate listing as a conversion page

## Expected Output

- `ASO-AUDIT.md` — full listing audit with keyword and conversion analysis
- `COMPETITOR-REPORT.md` — marketplace competitive intelligence
- `COPY-SUGGESTIONS.md` — optimized listing copy recommendations
- `LANDING-CRO.md` — listing conversion optimization

Save outputs to `outputs/shopplaza/`.
