# Workflow: Shopplaza B2B App Growth

## Purpose

End-to-end marketing workflow for growing installs and engagement for a specific Shopplaza B2B app.

## Required Context

- `brands/shopplaza/brand/` — brand identity and positioning
- `brands/shopplaza/shared/` — SEO, ASO, and content rules
- `brands/shopplaza/b2b/` — B2B context, funnel, audience, strategy
- `brands/shopplaza/b2b/apps/<app>.md` — specific app context

## Relevant Skills

1. `/market aso <app-listing-url>` — audit and optimize the app listing
2. `/market seo <shopplaza.io>` — evaluate website SEO and SEO-to-ASO bridge
3. `/market competitors <app-listing-url>` — competitive analysis in the app category
4. `/market funnel <shopplaza.io>` — map the install funnel
5. `/market social <topic>` — social content to drive awareness and installs
6. `/market emails <topic>` — email sequences for merchant engagement

## Execution Sequence

1. **ASO Audit** — Audit the app's marketplace listing for conversion and keyword optimization
2. **Competitive Analysis** — Identify competitors in the same Shopify App Store category
3. **Funnel Mapping** — Map the full journey from discovery to install to activation
4. **SEO Bridge** — Evaluate how website content supports app marketplace ranking
5. **Content Plan** — Generate social and blog content that drives install intent
6. **Email Nurture** — Create sequences for merchant engagement and cross-app adoption

## Expected Output

- `ASO-AUDIT.md` — listing optimization recommendations
- `COMPETITOR-REPORT.md` — competitive landscape
- `FUNNEL-ANALYSIS.md` — install funnel with drop-off points
- `SEO-AUDIT.md` — website SEO with ASO bridge assessment
- `SOCIAL-CALENDAR.md` — social content calendar
- `EMAIL-SEQUENCES.md` — merchant engagement sequences

Save outputs to `outputs/shopplaza/`.
